# マルチルームタイマー管理システム (Multi-Room Timer Management System)

本システムは、最大19部屋のタイマーを同時に管理できるWindows向けの業務用アプリケーションです。受付スタッフや店舗管理者が、各部屋のサービス時間を直感的に把握し、業務効率を向上させることを目的としています。

## 主な機能

- **🕐 直感的なタイマー管理**:
  - 19部屋の利用状況を一つの画面で一覧表示。
  - タイマーは開始・停止が可能で、残り時間がリアルタイムで更新されます。
  - 残り10分で警告色（黄色）、終了後は超過時間モード（サーモンピンク色）に自動で色が変わり、見落としを防ぎます。

- **📝 データ入力**:
  - 各部屋ごとに「キャスト名」「コース種別」を記録できます。

- **📊 自動EXCEL出力**:
  - ボタン一つで、全室の現在の利用状況（部屋番号、キャスト名、コース、開始・終了時刻など）をExcelファイルに出力します。
  - 日報作成や売上管理の手間を大幅に削減します。

- **💻 完全オフライン実行**:
  - 生成された`.exe`ファイルは、.NETランタイムがインストールされていないPCでも単体で動作します。

## 実行ファイル(.exe)の作成方法

このアプリケーションは、ソースコードから実行可能ファイル（`.exe`）をビルド（作成）する必要があります。ビルドを行うPCには、一度だけ **.NET 6 SDK** のインストールが必要です。

**ビルド手順:**

1.  **.NET 6 SDK のインストール**
    - まだインストールしていない場合は、[Microsoftの公式サイト](https://dotnet.microsoft.com/download/dotnet/6.0)から.NET 6 SDKをダウンロードしてインストールしてください。

2.  **プロジェクトの準備**
    - このプロジェクトフォルダ (`MultiRoomTimer`) をPCに配置します。

3.  **コマンドプロンプト/PowerShellの起動**
    - コマンドプロンプトまたはPowerShellを開き、`cd`コマンドを使ってプロジェクトフォルダに移動します。
      ```sh
      cd path\to\MultiRoomTimer
      ```

4.  **ビルドコマンドの実行**
    - 以下のコマンドを実行して、アプリケーションをビルド・発行します。
      ```sh
      dotnet publish -c Release
      ```

5.  **.exeファイルの確認**
    - コマンドが正常に完了すると、以下のパスに実行ファイルが生成されます。
      `MultiRoomTimer\bin\Release\net6.0-windows\win-x64\publish\`
    - このフォルダの中にある `MultiRoomTimer.exe` が実行ファイルです。

この `MultiRoomTimer.exe` ファイルを他のWindows PCにコピーすれば、ダブルクリックだけでアプリケーションを起動できます。

### キャスト一覧取得ツール (GetCastSchedule.exe) の作成方法

本アプリで使用するキャスト一覧を更新するためのツールも同様の手順でビルドできます。

1.  プロジェクトルートにある `publish_GetCastSchedule.bat` をダブルクリックして実行します。
2.  以下のパスに実行ファイルが生成されます。
    `GetCastSchedule\bin\Release\net6.0\win-x64\publish\GetCastSchedule.exe`

生成された `GetCastSchedule.exe` は、.NETランタイムがインストールされていない他のWindows PCでも単独で動作します。
